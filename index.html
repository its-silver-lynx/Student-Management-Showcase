01 / OVERVIEW

A focused backend project

A practical REST API for managing student records and connecting a Spring application to MySQL.

It demonstrates student CRUD operations, database integration, layered architecture, HTTP response handling with ResponseEntity, age validation during creation, and two deletion approaches.

The Java project is a backend API, not a completed frontend application. This page documents its design; it does not call a live API.

03 / ARCHITECTURE

One layer at a time

Requests move through focused layers before reaching persistent storage.

StudentControllerREST routes and HTTP responses
StudentServiceApplication logic
StudentRepositoryStudent data access
Spring Data JPA / HibernatePersistence and ORM

Clear responsibilities

The controller exposes the API, the service coordinates operations, and the repository works with student data through Spring Data JPA and Hibernate. MySQL stores the records.

04 / API REFERENCE

Implemented endpoints

Base URL for local development: http://localhost:8080/api/students

Method Endpoint Purpose
POST /api/students/create Create a student; age is validated.
GET /api/students/get?id={id} Retrieve an active student by ID.
GET /api/students Retrieve all active students.
PUT /api/students/{id} Update student fields.
DELETE /api/students/{id} Permanently delete a student.
PATCH /api/students/soft-delete/{id} Mark a student as deleted.

Individual retrieval and list operations exclude soft-deleted students. These are local API routes; this static showcase does not host or invoke them.

06 / GETTING STARTED

Run it locally

Set up the Java project and MySQL database, then send requests from Postman.

The current configuration uses Hibernate ddl-auto=update for schema updates during development. Production database configuration is not described here.

  1. Install Java 21, Maven, and MySQL.
  2. Create the database: 
    CREATE DATABASE student_crud_db;
  3. Set your local MySQL URL, username, and password in application.properties. Use your own credentials: 
    spring.datasource.url=jdbc:mysql://localhost:3306/student_crud_db
spring.datasource.username=<your-username>
spring.datasource.password=<your-password>
  4. From the Java project's root directory, run: 
    mvn spring-boot:run
  5. Test the endpoints using Postman.
