# Student Management REST API Showcase

A responsive, blossom-pink portfolio website showcasing my **Student Management REST API**, built with Java 21, Spring Boot, Spring Data JPA, and MySQL.

The website presents the project's features, architecture, API endpoints, local setup instructions, and learning outcomes. It is a static showcase and does not connect to or run the backend API.

## Technologies

- HTML5 and CSS3
- Vanilla JavaScript
- Google Fonts (DM Sans and Playfair Display, with system font fallbacks)
